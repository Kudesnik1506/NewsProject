# NewsProject — Claude Code Guide

## Проект

**NewsProject** — автоматизированный аналитический новостной агрегатор с мульти-агентной архитектурой. Специализация: геостратегия с уклоном в геопсихологию — анализ не только что происходит и кому выгодно, но и как события воздействуют на сознание элит, масс, союзников и противников.

Выходной продукт: Markdown-дайджест по стране за день или период (неделю и т.д.), разделённый на три части: верифицированные события (анализ по кластерам / тематические карточки с динамикой), непроверенные сигналы (краткий список "На радаре") и диагноз состояния государства по модели PAEI×Jung.

---

## Архитектура: 6-агентный пайплайн

```
User → Orchestrator
         ↓
      Collector → Filter → Verifier → Analyst → Reporter
                                                    ↓
                                            python/reports/{date}_{country}.md
```

Каждый агент — отдельный вызов Claude API. Данные между агентами передаются как JSON. Оркестратор координирует через `tool_use`.

### Агенты и файлы

| Агент | Файл промпта | Python-реализация | Роль |
|-------|-------------|-------------------|------|
| Orchestrator | `agents/orchestrator.md` | `main.py` | Координатор пайплайна |
| Collector | `agents/collector.md` | `agents/collector.py` | Сбор сырых статей (поддерживает диапазон дат) |
| Filter | `agents/filter_agent.md` | `agents/filter_agent.py` | Дедупликация, оценка релевантности (батчи по 50) |
| Verifier | `agents/verifier.md` | `agents/verifier.py` | Кросс-верификация источников (батчи по 20) |
| Analyst | `agents/analyst.md` | `agents/analyst.py` | Геостратегический + геопсихологический анализ (Q1–Q5) |
| PAEI Classifier | `agents/paei_classifier.md` | `agents/paei_classifier.py` | Системный диагноз состояния государства по PAEI×Jung |
| Reporter | `agents/reporter.md` | `agents/reporter.py` | Финальная сборка дайджеста: режим ДЕНЬ или ПЕРИОД |

## Модели данных (`models.py`)

```python
Article          # Одна статья: title, url, source, content, published_at, country,
                 # relevance_score, verification_status, source_count, verification_note

Scenario         # description + probability (высокая / средняя / низкая)

AnalyzedStory    # article + what_happened + interests + power_shift +
                 # psychological_dimension + scenarios + cluster

Report           # date + country + stories + total_sources + verified_count + file_path
```

**Важно:** `AnalyzedStory` содержит поле `psychological_dimension: str` — реализовано в analyst.md и models.py. `state_diagnosis` передаётся отдельно от `AnalyzedStory` — его производит PAEI Classifier, а не Analyst.

## Ключевые концепции

### Редакционная формула (5 вопросов Analyst)
1. Что случилось? (факты: кто, что, когда, где)
2. Какие интересы за этим стоят? (игроки, мотивации)
3. Как это меняет баланс сил? (кто усиливается / теряет)
4. **Психологическое измерение** — механизм воздействия, целевая аудитория, нарративы, когнитивные искажения
5. Какие сценарии наиболее вероятны? (2–3 сценария с вероятностью)

### Статусы верификации
| Статус | Условие |
|--------|---------|
| `VERIFIED` | 3+ независимых источника, нет противоречий → полный анализ в Части 1 |
| `UNVERIFIED` | 1–2 источника → краткий список "На радаре" в Части 2 |
| `DISPUTED` | Источники противоречат друг другу в фактах → исключается из дайджеста |

### Шкала relevance_score (0–10)
| Оценка | Значение |
|--------|----------|
| 9–10 | Критически важное: влияет на глобальный баланс сил или запускает масштабную психологическую операцию |
| 7–8 | Значимое: явные международные или геопсихологические последствия |
| 5–6 | Интересно в контексте: раскрывает паттерн поведения или нарратив |
| < 5 | Вне охвата — отсеивается фильтром |

### Тематические кластеры (PAEI × Jung)

8 кластеров по модели PAEI (Адизес) × экстраверт/интроверт (Юнг):

| Код | Кластер | Ось | Содержание |
|-----|---------|-----|-----------|
| P1 | геополитика | ext | Внешняя проекция силы: войны, санкции, запугивание |
| P2 | нацполитика | int | Внутреннее давление: элиты, кланы, здоровье тела-государства |
| A1 | геоэкономика | ext | Мировые торговые потоки, экспорт, рыночные позиции, стандарты |
| A2 | нацструктура | int | Внутренняя инфраструктура, импорт, цепочки поставок |
| E1 | геотренды | ext | Куда движется мир: AI, энергопереход, технологии, новый порядок |
| E2 | нацриски | int | Место государства: суверенитет, идеология, исторические нарративы |
| I1 | геодипломатия | ext | Внешние связи: альянсы, soft power, коалиции, саммиты |
| I2 | нацдипломатия | int | Внутренние связи: сплочённость, напряжение элит/народа |

**Топология:** E↔P (видение ↔ исполнение); A↔I (структура ↔ сплочённость); пары ортогональны.

Дайджест включает **Диагноз состояния государства** — оценку загрузки 8 измерений 0–10 и выявление дисбалансов по парам обратной связи.

## Соглашения

- Агенты не фильтруют и не интерпретируют данные вне своей роли — строгое разделение ответственности
- **Lean output pattern:** Filter и Verifier возвращают Claude-ответ с минимальным набором полей (`url` + скоры/статусы), Python-код мёрджит их обратно в полные статьи. Это решает проблему обрезания ответа при больших объёмах данных.
- **Батчинг:** Filter обрабатывает статьи батчами по 50, Verifier — по 20. Дедупликация по URL на Python-уровне после объединения батчей.
- Пайплайн не останавливается из-за сбоя одного агента — логировать, продолжать
- Язык дайджеста: русский
- Формат выходного файла: `reports/YYYY-MM-DD_{COUNTRY}.md` (день) или `reports/YYYY-MM-DD_YYYY-MM-DD_{COUNTRY}.md` (период)

## Режимы репортёра

| Режим | Условие | Формат Части 1 |
|-------|---------|----------------|
| ДЕНЬ | `--days 1` (по умолчанию) | Каждая история отдельно, группировка по 8 кластерам PAEI×Jung |
| ПЕРИОД | `--days N > 1` | Истории группируются по темам, каждая тема — карточка с "Динамикой", "Трендом", "Ключевыми сдвигами" |

Тренды в режиме ПЕРИОД: `нарастающая эскалация` / `деэскалация` / `стабильное напряжение` / `новая повестка` / `неопределённость`

## Конфигурация

- `MAX_TOKENS = 16000` — глобальный лимит токенов вывода для всех агентов
- `FILTER_BATCH_SIZE = 50` — размер батча для Filter Agent
- `BATCH_SIZE = 20` — размер батча для Verifier Agent
- `REPORTER_MAX_TOKENS = 16000` — лимит для Reporter (задаётся отдельно в reporter.py)
